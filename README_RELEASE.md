# 小鲸鱼喜欢你 0.5.1

个人非商业测试版 Android AI 陪伴与角色酒馆应用。

## 安装

- 包名：`com.xiagu.aicompanion`
- 版本：0.5.1（versionCode 50100）
- 支持：Android 8.0 及以上；主要面向 arm64 手机，同时包含 x86_64 模拟器库。
- 可直接覆盖同签名旧版安装；若系统提示签名不一致，只能先备份数据，再卸载冲突版本。

首次进入会显示中文教程。之后可从“设置 → 帮助”重新打开。

## 核心功能

- 小女友：独立人设、记忆、无聊值、主动消息、联网搜索、打开应用、图片理解、语音与 Live2D。
- 酒馆：角色卡、预设、正则、世界书、群聊、图片生成、导入与备份等原有能力。
- 手机端独立联网，不需要电脑中转。

## 重要限制

小女友不会读屏、自动点击、读取或修改文件、浏览相册、调节系统设置，也不会代发微信/短信。打开应用不代表她能看到应用内部内容。

## 隐私与费用

聊天和本地配置保存在手机中；模型、视觉、语音与搜索请求会发送给你选择的第三方服务商，并可能产生费用。请勿提交 API Key 以外的账号密码、支付信息、隐私照片或重要文件。
